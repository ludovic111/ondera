    Command layer

    One command layer. Three clients. None of them privileged.

    The desktop app, command-line tool and MCP server share 78 validated commands for sessions, tracks, notes, plugins, automation and exports. Agent edits use the same undo history as manual edits. Native dialogs and plugin windows remain interface controls.

    GUI

    Click it

    BGVAudio

    The native button dispatches track.setMute through the command store. Persistent edits share the session’s undo and redo history.

    CLI

    Type it

    $ ondera-cli track.setMute --trackId bgv --muted false
ok  session 3f9c · undo #12

    The CLI is generated from the command registry, not hand-written. New command in core, new subcommand in the shell.

    MCP

    Ask for it

    {
  "name": "track_setMute",
  "arguments": { "trackId": "bgv", "muted": false }
}

    MCP tools expose the same parameter schemas. The Agents tab runs tasks through your installed, signed-in Codex CLI; prompts and tool results go to its model provider.

    Material system

    Feels like hardware, because it is drawn like hardware.

    One light source, directly above. Every raised object gets the same four layers in the same order: a specular highlight on its top edge, a face that darkens downward, a contact line along the bottom, and a soft drop shadow.     Architecture

    API first. The GUI is just one client.

    Ondera’s native interface, CLI and MCP server share a Rust command registry and session store. The live bridge applies commands between interface frames; audio processing runs separately from file operations and the interface.

    Native Rust UIegui + wgpu
    CLIgenerated from the registry
    MCP servergenerated from the registry
    ondera-engine command registry · session store · model · undo · dispatch(command) Rust session model · validated edits · shared history
    prepared graphs · bounded queues
    Audio engine native Rust DSP and device audio stock, CLAP, VST3 and macOS Audio Units
    • Edits go through the store. The interface keeps hover and drag previews local. Persistent changes dispatch commands and participate in undo.
    • One shared registry. CLI help and MCP tool schemas come from the same command definitions. Compact queries inspect the arrangement without returning opaque plugin state.
    • Consistent materials. The native app centralizes its visual tokens and drawing helpers. This site preserves the original palette and material recipes.
