# Ondera 0.5.0

## Mixer

Press `X`, choose View > Mixer, or call `ui.showPanel --panel mixer` to swap the region editor
for a mixer: one strip per track with pan, fader, mute, solo, record arm, insert count and a
live post-fader meter, plus the master. The engine now publishes a peak for each of the first
32 channels from the audio callback (fixed-size atomics, no allocation); later tracks still play
but read as silent in the mixer. The strips dispatch the same commands as the inspector and the
track headers, so every move is undoable.

## Faster editing

- Command palette (`⌘P` / `Ctrl P`): every menu command and every action, searchable by name,
  with its shortcut, enabled state and tick. It is built from the menus and the action table,
  so it cannot list something the menus would not do.
- Copy, cut and paste regions (`⌘C`, `⌘X`, `⌘V`). Paste lands at the snapped playhead on the
  selected track when its kind matches, otherwise on the region's own track, in one undo step.
- Duplicate a track with its strip and regions (`⇧⌘D`, Track menu, track context menu).
- Transpose the selected note or region with `⌥↑` / `⌥↓`, and by octaves with `⇧⌥↑` / `⇧⌥↓`.
- Drop WAV, AIFF, FLAC, MP3, Ogg or AAC files from the file manager onto the window to import
  them. Double-clicking a file in the browser's Files tab places it at the playhead.
- The Track menu gains mute, solo, arm and delete; the snap grid goes down to 1/64.
- Help > Shortcuts and Help (`⌘/`) is generated from the action table instead of hand-written.

## Fixes

- The Files tab promised "double-click: open or import" and did nothing.
- The grid tool was advertised on key `4` but is not a host tool; it is removed.
- The Agent menu's "Stop" is now "Stop agent", so it no longer reads like the transport's Stop.

## Site

The site leads with what a musician can do, shows captures of the real window, lists what comes
with you when switching and what is not built yet, answers common questions, and offers a direct
download for the visitor's platform (`/download`, `/download/<platform>` redirect to the latest
release asset). The server adds a content security policy and the usual security headers.

## Validation and limits

Local macOS validation: frontend type check and 54 frontend tests, `cargo fmt`, Clippy with
warnings denied, the workspace tests, and a debug build driven through the CLI: the mixer was
opened with `ui.showPanel`, the demo played, and a capture of the real window showed per-track
meters moving. The command palette, clipboard, transposition and file drop are covered by unit
tests and type checks; they were not driven by hand in the packaged app on Windows or Linux.

Still not built: clip fades and gain, time stretching, comping, tempo changes inside a song and
user-defined buses. Packages remain ad-hoc signed without notarization; Windows binaries remain
unsigned.
