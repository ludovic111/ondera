# Ondera 0.9.0

## Sound
- Stock instruments leave 6 dB of headroom. At unity gain the Four Floor loop used to peak at
  +3 dBFS on its own and a five-note chord clipped on every stock instrument; the loops now sit
  between −26 and −3 dBFS. Songs made with earlier versions play 6 dB quieter on stock
  instruments, with the balance between them unchanged: raise the master or the faders if you
  mixed hot.
- Stock effects glide to a new parameter value in about 10 ms, so moving a dial and fast
  automation no longer click or step every 32 samples. A freshly loaded effect starts on its
  values instead of gliding from its defaults.
- A new song plays at once: Drums on the Drum Machine, Bass on Analog Bass, and an audio track,
  Vocals, to record into (it used to open with a silent audio Drums track).

## Files
- Undone audio imports no longer count toward the 1 GiB import budget.
- `session.importMidi importTempo=true` keeps automation on its bars when it changes the meter.
- Short Ogg Vorbis files import at their exact length (they ran a few milliseconds long).

## Interface
- At the 1120 px minimum width with the agent panel open, the side panels give way so the
  arrangement keeps its lanes (it was about 60 px wide). The agent tabs shorten, the inspector
  stacks its sends, the browser tabs no longer run into each other and the transport no longer
  clips the Agent button.
- The playhead's position bubble sits above the marker flags, so it never hides a section name.
- The agent conversation keeps each message's state when older ones are trimmed.

## Documentation
- A user guide (`docs/USER_GUIDE.md`), a keyboard shortcut list generated from the app's action
  table (`docs/SHORTCUTS.md`) and a command reference generated from the registry
  (`docs/COMMANDS.md`). Tests fail when either list is out of date.
