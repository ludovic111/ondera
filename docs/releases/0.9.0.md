# Ondera 0.9.0

## AI control of everything
- Everything a person can do in the window is a command the built-in agent, `ondera-cli` and MCP
  clients can call: an audit of 213 window interactions found 184 already covered, closed 17
  gaps and left 12 deliberately with the person (signing in, agent permissions, pure layout).
  `docs/AGENT_PARITY.md` lists them, and a test fails when a new window action has no command.
- `session.overview`: the whole song in one bounded answer, including what keeps a track silent,
  the parameters changed on every plugin and, in the app, what the window shows. The built-in
  agent reads a compact one at every turn; MCP offers it as `ondera://session/overview`.
- `ui.state`: open panels and dialogs, plugin windows, the editor, zoom, tool, selection, theme.
- Names work wherever ids do (`--trackId Bass`), and a wrong name lists what exists and the
  closest match.
- External plugins, fully: load any CLAP, VST3 or Audio Unit by name into the first free slot;
  list every parameter with its display text, range, 0–1 position and automation lane, search
  them by name, set them as a number, a position or display text ("-4.5 dB", "Hall"); load the
  plugin's own factory programs (`strip.programs`, `strip.setProgram`: VST3 program lists and
  Audio Unit factory presets); remove an insert (`strip.removeInsert`); automate a parameter by
  name.
- `plugin.list` finds plugins by what they do ("reverb", "compressor", "saturation") as well as
  by name and vendor, best match first.
- A number given as text (`value="-6 dB"`) is refused with a pointer to `text`.
- Automation lanes are named after what they drive ("Drums · Pro-Q 3 · Band 1 Gain").
- Screenshots show the window settled: a panel opened in a window behind others was captured
  transparent, with button labels half faded.
- A command issued right after a program change, an undo or a new song no longer reads the
  plugin's previous state (or another song's plugin under a reused key).
- 182 commands.

## Six themes
- Three new themes, each in dark and light: **Console** (a warm analogue desk: walnut, brass
  keys, amber meters), **Ink** (paper and ink, flat and square, one red accent, selection shown
  reversed) and **Neon** (violet glass lit from inside, magenta and cyan). Every one of the twelve
  variants passes the contrast checks.

## Sound
- Stock instruments leave 6 dB of headroom. At unity gain the Four Floor loop used to peak at
  +3 dBFS on its own and a five-note chord clipped on every stock instrument; the loops now sit
  between −26 and −3 dBFS. Songs made with earlier versions play 6 dB quieter on stock
  instruments, with the balance between them unchanged: raise the master or the faders if you
  mixed hot.
- Stock effects glide to a new parameter value in about 10 ms, so moving a dial and fast
  automation no longer click or step every 32 samples. A freshly loaded effect starts on its
  values instead of gliding from its defaults.
- Changing a region's gain or fade while it plays glides instead of clicking.
- A new song plays at once: Drums on the Drum Machine, Bass on Analog Bass, and an audio track,
  Vocals, to record into (it used to open with a silent audio Drums track).

## MIDI
- Controllers, pitch bend and pressure also reach insert effects that accept events (native
  ABI 2 effects, CLAP effects with a note port, VST3 effects with an event bus, AU music effects).
- Notes and controllers keep their MIDI channel, live, in takes, in regions and in MIDI files.
- Polyphonic aftertouch is recorded and played back.
- A VST3 plugin's window follows parameters moved by mapped controllers.

## Plugins and files
- One browser row per plugin across formats: a plugin installed as CLAP, VST3 and AU is one row
  (a 2,244-plugin library now shows 875 rows). The row loads CLAP, then VST3, then AU.
- Undone audio imports no longer count toward the 1 GiB import budget.
- `session.importMidi importTempo=true` keeps automation on its bars when it changes the meter.
- Short Ogg Vorbis files import at their exact length (they ran a few milliseconds long).

## Interface
- At the 1120 px minimum width with the agent panel open, the side panels give way so the
  arrangement keeps its lanes (it was about 60 px wide). The agent tabs shorten, the inspector
  stacks its sends, the browser tabs no longer run into each other and the transport no longer
  clips the Agent button.
- The playhead's position bubble sits above the marker flags, so it never hides a section name.
- The agent conversation keeps each message's state when older ones are trimmed.
- Rhythm Lab's Preview works again, the Stop Agent menu item enables while the agent runs, the
  Mix menu's device items open Settings at Audio, and note tools are disabled on audio regions.

## Documentation
- A new README, a user guide (`docs/USER_GUIDE.md`), a guide to AI control
  (`docs/AI_CONTROL.md`) and a developer guide (`docs/DEVELOPMENT.md`).
- A keyboard shortcut list generated from the app's action table (`docs/SHORTCUTS.md`) and a
  command reference generated from the registry (`docs/COMMANDS.md`); tests fail when either is
  out of date.

## Site
- One look instead of a theme switcher, redesigned: numbered sections, a spec-sheet feature
  grid, a release timeline, scroll reveals, a scroll-progress line and a gallery of the six app
  themes in dark and light from real screenshots. All motion respects reduced motion, and the
  page still makes no third-party requests.

## Known limits
- The Audio Unit factory presets and plugin search were tried on the Mac's real library;
  VST3 program lists, controller routing to inserts, MIDI channels and poly aftertouch are
  covered by tests only, not yet by a real keyboard and third-party plugins.
- CLAP preset discovery and presets a plugin only shows inside its own window are not reachable
  from commands.
- Monitoring and the count-in have still not been tried with an audio interface.
