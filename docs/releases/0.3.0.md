# Ondera 0.3.0

The window now matches the Claude Design arrangement frame (`design/Ondera Arrangement.dc.html`),
and the agent tab is the design's simple right-hand panel.

- **Agent panel:** a 380 px panel at the right edge (32 px rail when closed) with a header, the
  current-action card while Codex works, the log of changes this session and one prompt with
  ⌘↵ to send. Every command from Codex, an MCP client or `ondera-cli` lands in the log with its
  CLI spelling and a Revert or Redo button that walks the undo stack; reverted entries show
  struck through. Sending a prompt starts the local bridge if it is off.
- **Agent menu:** the title bar gains an Agent menu holding show/hide, Stop task, the local
  bridge toggle, Copy MCP config, Copy CLI check and the Codex CLI executable and model. The
  former command workbench is gone; the CLI and MCP tools cover it.
- **Window chrome:** menus follow the design (File Edit Track Mix Agent View Help). On macOS the
  native title bar is hidden so the traffic lights sit in Ondera's own bar, which drags the window
  and zooms on double-click. The transport gains the Agent button; the browser drops the
  Library/Agents switch and names its third tab Plugins.
- **Piano roll:** the header matches the design; the grid scrolls octaves with the wheel and zooms
  time with pinch or ⌘-wheel, replacing the Low and Zoom sliders.

Everything else is unchanged from 0.2.0, including its documented limits. macOS packages remain
ad-hoc signed without notarization; Windows packages are unsigned.
See [0.2.0 notes](https://github.com/ludovic111/ondera/blob/v0.3.0/docs/releases/0.2.0.md),
[plugin details](https://github.com/ludovic111/ondera/blob/v0.3.0/docs/PLUGINS.md) and
[verification](https://github.com/ludovic111/ondera/blob/v0.3.0/docs/VERIFICATION.md).
