# Ondera 0.4.0

## Tauri desktop interface

Ondera now opens in a Tauri 2 window with a React/TypeScript renderer, using the existing
interface as its visual reference: transport, browser, arrangement, MIDI editor, inspector,
plugin controls and agent panel. This release changes the rendering technology; audio
processing, project state, undo history, recording, export and plugin hosting remain in Rust.

The interface uses the same command registry as the CLI, MCP and built-in agents. It displays
real decoded waveform peaks and receives bounded transport updates. Project snapshots omit
plugin state blobs, and stale snapshots are ignored. Packaged applications embed the frontend
and do not need Node.js or a development server.

## Desktop behavior

- Native file dialogs and unsaved-change confirmation, including quitting from the macOS menu.
- Connected track and region editing, piano roll, instrument and effect controls, sends,
  automation, settings, recovery, audio export and agent history.
- Musical typing releases held notes when the window loses focus; pointer gestures share one
  undo step. Space controls transport after interacting with toolbar buttons.
- macOS screenshots use the WebView's native snapshot API, including canvas content.
- Existing `.ondera` projects and Rust CLI/MCP workflows remain supported.

## Installation and requirements

Use the macOS archive matching your processor, or the Windows/Linux portable archive.
The portable archives include `ondera`, `ondera-cli` and `ondera-mcp`.

- macOS uses the system WebKit runtime.
- Windows requires Microsoft Edge WebView2 Runtime.
- Linux requires WebKitGTK 4.1 and the native audio/window libraries documented in the README.

Download checksums are signed with the existing release key and verified by the updater.
macOS bundles remain ad-hoc signed without notarization; Windows binaries remain unsigned.

## Validation and limits

Local macOS validation covered 193 Rust tests, 10 frontend tests, Clippy, the optimized build
and packaging. The complete composition/save/reopen/MIDI/WAV/stems workflow also passed
through CLI and MCP against a running Tauri window with the development server stopped.
The release workflow requires the platform checks, tests, optimized build and song workflow
on macOS ARM64, macOS Intel, Linux and Windows before publishing.

A complete manual comparison of every interface gesture and dialog is still pending.
Windows/Linux graphical behavior and the non-macOS screenshot fallback have not been
manually verified. No numerical performance gain or loss is claimed. The former egui painting
code remains as migration reference but is not used to render the Tauri window.

See [migration details](https://github.com/ludovic111/ondera/blob/v0.4.0/docs/TAURI_MIGRATION.md)
and [installation instructions](https://github.com/ludovic111/ondera/blob/v0.4.0/README.md).
