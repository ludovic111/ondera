# Ondera 0.2.0

Ondera now brings recording, arrangement, stock and external plugins, and agent control into the
same native Rust application. Write or record MIDI, import or record audio, edit regions, mix
through track/aux/master strips, save the project and export stereo WAV or track stems.

- **Agents tab:** describe a musical task and run it through your authenticated Codex CLI.
  Progress, final responses and actual session commands are visible; Stop keeps completed edits
  in Undo history. Runs expose only this window's Ondera tools. The command workbench and copied
  MCP configuration also support other clients; no model or credentials are bundled.
- **CLI and MCP:** control recording, the master fader, all eight insert slots and generic plugin
  parameters/state. Track, master and both aux strips use the same commands. Live open, save,
  import, export and scanning run on workers so the window continues to repaint. The shared
  registry has 78 commands; compact session inspection, a stock-only catalog and searchable
  plugin pages keep routine agent queries small.
- **Plugins and mixing:** use the stock library or installed CLAP, VST3 and macOS Audio Units.
  Save, export and the unsaved-close check capture plugin state; native-editor changes participate
  in undo and the save/discard prompt. Static latency compensation aligns parallel track and
  aux paths; exports remove the initial reported plugin latency. Failed plugin loads produce
  an error instead of silently changing the exported mix.
- **Audio export settings:** choose 44.1/48/96 kHz, 16/24-bit PCM or 32-bit float, dither, a full
  arrangement or bar range and the release tail. Track stems export into a new folder, with
  optional effects/sends and master processing. Completion reports include clipping and warnings.
- **Live MIDI:** CC64 sustain holds playback notes and extends recorded note lengths. Retrigger,
  Stop and input disconnect release held notes; interrupted input retains the recorded part.
- **MIDI interchange:** import Standard MIDI Files into new tracks, optionally using the initial
  tempo/meter, and export selected instrument-track notes. Ignored controller and tempo-map data
  are reported, including imported CC64; plugin audio is not embedded in MIDI files.
- **Read automation:** edit linear or stepped lanes for track volume/pan, the master fader and
  instrument/insert parameters. Points use musical beats and support drag editing, precise
  numeric values and undo. Playback and export read the saved lanes.
- **Recorded audio:** completed microphone takes retain a separate float32 source WAV.
  Interrupted capture preserves partial audio with a warning; failed placement shows the
  recovery path, and failed disk backup can be retried without dropping the in-memory take.
- **Recovery copies:** dirty sessions receive separate periodic snapshots when idle. File >
  Recover session lets you choose a snapshot and handles current unsaved edits before opening
  a copy. The original project is preserved.
- **Project ownership:** one editing owner per saved project across desktop windows and file-mode
  tools prevents competing saves. `--live` shares the visible session; OS locks release on exit
  or crash, while small sibling lock files intentionally remain.
- **Distribution:** macOS app bundles and Linux/Windows archives include matching `ondera-cli`
  and `ondera-mcp` companions. Updates verify SHA-256 checksums and replace the full set; Linux/Windows
  ZIPs require all three matching versions and restore prior files if installation fails. The
  downloadable Afterglow demo includes a stock-plugin project, WAV, MIDI and verification report.

This release supports a complete linear song workflow within its current feature set. Automation
write modes, time stretching, comping, hardware recording latency compensation, VST2 and AAX are not
implemented. External plugin editors are macOS-only; generic parameter controls work across
platforms. Dynamic plugin latency changes and arbitrary sidechains/multiple audio buses are not
supported. The Codex runner requires a compatible installed CLI and login; prompts and tool
results are sent to its model provider. Pitch bend, MPE and general MIDI CC control are not
implemented. Active recording is held in memory until the take finishes, so recovery does not
protect an unfinished take from a process crash.

macOS packages are ad-hoc signed without Developer ID notarization; Windows packages are unsigned.
