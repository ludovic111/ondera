# ryolune 0.11.0

Follows Ondera 0.10.0 (tempo changes, bus tracks) a day later, under a new name.

## Ondera is now ryolune

The project is renamed ryolune, written in lowercase: the app, `ryolune-cli`, `ryolune-mcp`,
the plugin SDK (`ryolune-plugin`), the site and the repository (github.com/ludovic111/ryolune;
the old address redirects). Nothing you made is left behind:

- **Songs.** New sessions are saved as `.ryolune`. `.ondera` files open unchanged, keep their
  name when you save them again, and show up in the Open dialog next to new ones.
- **Settings, presets, recovery snapshots and the plugin cache** move from the old data folder
  (`~/Library/Application Support/Ondera` on macOS, `%APPDATA%\Ondera` on Windows,
  `~/.config/ondera` on Linux) to the `ryolune` one the first time the app starts. If the
  move is not possible, the old folder is used where it is.
- **Native plugins** built with the Ondera SDK load as before: hosts look for the
  `ryolune_plugin_entry` symbols first and the former `ondera_plugin_entry` ones after, and
  plugins built with `ryolune-plugin` export both names so older hosts load them too. Plugin
  folders under the old name (`Plug-Ins/Ondera`, `Ondera/Plugins`, `lib/ondera/plugins`) are
  still scanned.
- **Scripts and MCP clients**: the executables are `ryolune`, `ryolune-cli` and `ryolune-mcp`,
  the environment variables `RYOLUNE_*` (`RYOLUNE_DATA_DIR`, `RYOLUNE_CONTROL`,
  `RYOLUNE_NO_UPDATE`, ...) and the MCP server name `ryolune`. Re-add the server:
  `claude mcp add ryolune -- /Applications/ryolune.app/Contents/MacOS/ryolune-mcp --live`.
- **Updating from Ondera 0.10 or older**: those versions look for releases under the old
  name and cannot install this one themselves. Download ryolune once from the site or the
  release page; it updates itself from then on.

## Opens on a Mac without a warning

- macOS builds are signed with a Developer ID, run under the hardened runtime and are notarized
  by Apple, with the ticket stapled. Gatekeeper opens them like any other app: no more System
  Settings > Privacy & Security > Open Anyway. Microphone recording and third-party CLAP, VST3
  and Audio Unit plugins keep working (the entitlements are in `desktop/ryolune.entitlements`).
- Updating from 0.10.0 or older through Help > Check for updates… installs the notarized app;
  the updater's checks (Ed25519 checksums, download host, `codesign --verify`, binary versions)
  are unchanged.

## Pay what you want, once

- ryolune stays free and MIT licensed, with nothing locked. Help > Support ryolune… and Settings >
  About > Support ryolune… open the page where you can pay what you want for it, one time: no
  subscription, no account.
- The window asks once, after your third export, and never again. It counts exports in
  `settings.json` only (`general.exportsCompleted`, `general.supportAsked`); nothing is sent.
- `app.openGuide guide=support` opens the same page from the CLI, MCP clients and the agent.

## Project
