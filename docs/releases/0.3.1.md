# Ondera 0.3.1

Follows 0.3.0 (the Claude Design window frame) a few hours later with everything below.

## The fourth way to control Ondera

- **Built-in agent.** The Agent panel is now a conversation, drawn like a coding agent's
  harness without the code: your prompts, the assistant's replies as they stream, one card per
  tool call with its arguments and result, and a Revert button on every edit. Choose the brain
  in Settings > Agent: the Codex CLI or Claude Code CLI with their own sign-in, the Anthropic or
  OpenAI API with a key, or any OpenAI-compatible endpoint (local models included). Every
  provider uses the same command registry as `ondera-cli`, so nothing an agent does is special.
- **Agent permissions.** File operations, transport, replacing the session, changing settings
  and application control are switches; they apply to the panel, MCP clients and `--agent`.

## Settings

- A Settings window (⌘,) with General, Audio & MIDI, Interface, Agent, Plugins, Control, Updates
  and About. Changes apply at once and are stored in `settings.json`, readable only by you.
  `settings.get` / `settings.set` expose the same document to the CLI, MCP and agents.
- Audio devices and the MIDI port persist across launches; interface scale, recovery interval,
  reopen-last-session, plugin folders, the local bridge and update behaviour are all settings.

## Ondera native plugins

- `ondera-plugin`, a Rust SDK with a `Plugin` trait, DSP primitives and a frozen C ABI generated
  by `export_plugins!`. Build a `cdylib`, drop it in a plugin folder, rescan. See
  `docs/NATIVE_PLUGINS.md`.
- All 24 stock plugins are rewritten on the SDK and loaded through the same vtables as
  third-party libraries, so the plugin path is exercised on every run. Sessions load unchanged.
- Factory presets for the stock library, user presets for any plugin, from the plugin window or
  `preset.*` commands.

## Full parity for the CLI and MCP

- New commands: `view.get/set`, `clip.quantize`, `clip.transpose`, `track.duplicate`,
  `strip.moveInsert`, `plugin.describe`, `preset.*`, `settings.*`, `audio.*`, `note.preview`,
  `ui.screenshot` (agents can see the window), `ui.showPanel`, `ui.openPluginWindow`,
  `ui.musicalTyping`, `ui.setTool`, `ui.status`, `app.info/checkUpdates/installUpdate/quit`,
  `session.snapshots/restoreSnapshot` and `agent.*`. `history.undo` takes `steps`.
- `ondera-cli batch` runs JSON lines from stdin; `ondera-cli doctor` checks the bridge,
  versions, companions, settings and plugin cache; `commands --json` prints the schema.
- `ondera-mcp` serves prompts (`compose`, `mix-review`, `see-the-window`) and resources for
  settings, plugins, presets and the app, with honest destructive hints.

## Hardening

- Releases are signed: `SHA256SUMS.sig` (Ed25519) is verified against the key built into the
  app before anything is downloaded. Downloads must come from this repository's releases, and
  the fresh macOS bundle must report the expected version before it replaces the installed copy.
- Agent CLIs run in their own process group with a read-only sandbox and only this window's
  tools; API keys never appear in argv or logs; settings redact secrets.

## Interface

- Faceplates with screws behind plugin, settings, automation, export and recovery windows;
  brushed bars; LED buttons; knob tick rings; glossy clips; ivory and lacquered piano keys;
  frosted dialogs.

Limits carried over from 0.2.0 and 0.3.0 still apply. macOS packages remain ad-hoc signed
without notarization; Windows packages are unsigned.
